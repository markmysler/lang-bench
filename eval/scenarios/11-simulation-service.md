# 11-simulation-service

**Team:** research-lab

## Situation

Collaborators at three other universities want to run the lab's protein-folding simulation on
their own inputs. One run takes 20 to 90 seconds of CPU with NumPy. Maybe 20 users, a few dozen runs
a day. Today the researchers run it by hand on the cluster and email the results.

## The request

> How should we put our simulation online so collaborators can submit jobs? Do we need to learn a faster language for the web part?
